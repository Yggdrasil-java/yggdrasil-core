# yggdrasil-core

Módulo Java 25 do Yggdrasil.

Fontes e contrato: [core/README.md](core/README.md).

## Build

Instale primeiro as dependências Yggdrasil conforme [a organização dos repositórios](docs/github-repositories.md).

```sh
./mvnw verify
./mvnw install
```

A documentação e os exemplos compartilhados são referências da exportação inicial. Comandos que verificam o reactor completo devem ser executados no workspace original.
